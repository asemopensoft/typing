# ⚡ Barqtype - سباق الطباعة السريعة التفاعلي (Online Touch Typing & Multiplayer Race)

منصة متطورة واحترافية للتدريب على الطباعة باللمس والسباق عبر الشبكة مع منافسين في الوقت الفعلي، بتصميم مستوحى من لوحات المفاتيح الميكانيكية الفاخرة (IQUNIX A80) وتأثيرات صوتية واقعية (Razer Green Switches).

---

## 🌟 أبرز المميزات (Features)

- 🏎️ **سباق عبر الشبكة في الوقت الفعلي (Real-Time Multiplayer Race)**:
  - إنشاء غرفة برمز تلقائي من 4 أحرف ومشاركته مع المنافسين.
  - إمكانية تحديد مدة السباق (15s، 30s، 60s، أو النص الكامل).
  - مسارات سباق متحركة تظهر تقدم وسرعة كل لاعب بدقة.
  - فترة سماح نهائية (Grace Period) مدتها 5 ثوانٍ عند وصول أول لاعب لخط النهاية.
- 🏆 **شاشة نتائج واحتفالات بنمط الرياضات الإلكترونية (Esports Champion & Podium)**:
  - احتفالات فرح وتأثيرات جسيمات وقصاصات ورق (Canvas Confetti Cannon).
  - ألحان صوتية نصر مخصصة (Web Audio Victory Fanfare).
  - إبراز اسم البطل الفائز وسرعته وفارق السرعة بين المتنافسين.
  - إمكانية إعادة السباق فوراً (Rematch) ومزامنة كلا اللاعبين للعودة إلى الغرفة تلقائياً.
  - نسخ ملخص النتيجة للمشاركة على وسائل التواصل.
- ⌨️ **محاكي لوحة مفاتيح ميكانيكية متقدم (Mechanical Keyboard Visualizer)**:
  - دعم كامل للغتين: **العربية** و **الإنجليزية**.
  - تبديل تلقائي وتطابق فوري ومزدوج للحروف (Dual-Layout Matching).
  - محاكي أصوات سويتشات ميكانيكية Razer Green واقعية بدون أي ملفات خارجية.
- ⚡ **أداء فائق واستجابة لحظية (Zero-Latency Typing)**:
  - كتابة فائقة السرعة مع منع تداخل المفاتيح عند كتابة الأسماء أو الرموز.
  - إحصائيات حية: الكلمات في الدقيقة (WPM)، الدقة (Accuracy)، عدد الأخطاء، والوقت المستغرق.

## 🚀 كيفية التشغيل محلياً (Running Locally)

### 1. تشغيل خادم السباق (Race Server):
```bash
cd server
npm install
node server.js
```
سيعمل الخادم على المنفذ `http://localhost:3001`.

### 2. فتح المنصة (Frontend):
يمكنك فتح ملف `Barqtype.html` مباشرة في أي متصفح، أو فتح الرابط من السيرفر المحلي:
```
http://localhost:8080/Barqtype.html
# أو مباشرة
http://localhost:8080/
```

## 🌐 النشر والاستضافة (Deployment)

الخادم يدعم النشر السهل على منصات السحاب مثل:
- **Render** / **Railway** / **Heroku**
- يحتوي مجلد `server` على ملف `Procfile` جاهز.
- يمكن للعملاء في اللعبة إدخال عنوان الخادم السحابي من أيقونة الإعدادات ⚙️ للاتصال واللعب عبر الإنترنت من أي مكان في العالم!

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend**: HTML5, Vanilla CSS3, Modern JavaScript (ES6+), Canvas Confetti, Web Audio API.
- **Backend**: Node.js, Express, Socket.IO.
- **Real-Time Communication**: WebSockets with auto-reconnection.
